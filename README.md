# FinTech Payment Analytics

## Project Overview
FinTech Payment Analytics is a data analytics project focused on analyzing digital payment transactions, customers, merchants, payment methods, and transaction status.

## Tools Used
- SQL
- Excel
- Power BI

## Project Analysis
- Payment transaction volume and amount
- Successful and failed transactions
- Payment method analysis
- Customer-wise transaction analysis
- Merchant-wise transaction analysis
- Customer and merchant trends
- Category-wise payment analysis

## Power BI Dashboard
The Power BI dashboard contains 4 pages:
1. Payment Overview
2. Customer & Payment Analysis
3. Customer & Merchant Analysis
4. Merchant & Category Analysis
